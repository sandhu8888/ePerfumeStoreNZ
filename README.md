## 🚀 Pushing to Your GitHub Repository

To link this codebase to your own GitHub account:

1. **Create a new repository on GitHub**:
   - Go to [https://github.com/new](https://github.com/new)
   - Name it `eperfumestore` (or your preferred name)
   - Keep it Public or Private, and do not initialize with a README (as we already have one).

2. **Run the following commands in your terminal**:
   ```bash
   # Add your GitHub repository as the remote origin:
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/eperfumestore.git

   # Push the code to GitHub:
   git branch -M main
   git push -u origin main
   ```

3. **Deploy to Vercel (1-Click)**:
   - Go to [https://vercel.com/new](https://vercel.com/new)
   - Import the `eperfumestore` repository from GitHub
   - Framework preset: `Vite`
   - Click **Deploy**!

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Run TypeScript linter
npm run lint

# Build for production
npm run build
```
