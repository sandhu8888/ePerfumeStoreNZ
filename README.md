# ePerfume Store New Zealand (`eperfumestore.com`)

Official luxury e-commerce web platform for **ePerfume Store**, based in **Shop 3/24 Leven Street, Invercargill 9810, New Zealand**. Retailer of **Naseem Perfume UAE** (100% alcohol-free concentrated perfume oils, luxury EDPs, and ambient home air fresheners).

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Run TypeScript linter
npm run lint

# Build for production
npm run build
```
